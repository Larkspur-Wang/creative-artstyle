# POV Video Formula / 6 格公式

一个有视角限制的角色，在一个有规则的世界里，撞上一个错位，产生可见后果。

## 6 格公式

每条 POV 内容填这 6 个格子，填出来的组合自然带味道，不需要先选类型：

| 格子 | 含义 | 示例 |
|---|---|---|
| 视角身份 | 谁在看 | 水鬼 / 守卫 / 实习生 / 玩家 / 穿越者 |
| 视角限制 | 只能看到 / 不知道什么 | 不知道自己是"被刷的" |
| 世界规则 | 这个世界怎么运转 | 游戏机制 / 社会制度 / 物理规则 |
| 错位事件 | 预期 vs 现实撞车 | 以为普通流程，世界却反预期 |
| 可见后果 | 画面能拍到的结果 | 被清场 / 表格爆炸 / 世界变形 |
| 识别锚点 | 圈内人一秒认出 | 地标 / 道具 / 系统提示 |

事件句模板：

> 当【视角身份】想【小目标】时，以为只是【普通流程】，但【世界规则】返回【反预期阻力】，最终导致【可见后果】。

## 硬规则

- 遮名测试：遮掉 IP 名，圈内人还能从地点、动作、机制认出。
- 至少 3 个识别锚点。
- 首帧 1 秒内有视觉锚定，且至少一个正在参与事件。
- 世界在 3 秒内给第一轮反馈，不要前 7 秒纯蓄力。
- 台词短、干、不解释；后果靠画面，不靠旁白。
- 视角限制全程贯穿：角色只能看到 ta 能看到的。

## 多段视频交付契约

- 用户确认 N 段脚本，就必须交付 N 段 + 拼合版。不允许只交 S1 当完成品。
- 连续故事：顺序生成，每段共用同一组角色/场景/道具参考图，上一段尾帧只作为多张参考图之一。
- 主题合集：可并行独立生成，硬切拼合。
- 状态必须逐段可见：S1 done / S2 done / S3 review / S4 queued / 拼合 pending。

## 15s 节奏模板

| 时间 | 功能 |
|---|---|
| 0-3s | 开场已在麻烦中，不铺垫 |
| 3-6s | 角色按自己逻辑处理 |
| 6-9s | 世界规则制造反预期阻力 |
| 9-12s | 情绪/后果升级 |
| 12-15s | 可见后果收束 |
