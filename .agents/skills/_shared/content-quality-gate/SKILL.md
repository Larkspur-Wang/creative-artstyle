# Content Quality Gate

先证明内容能提供真实观看回报，再选择兑现回报的结构。这是诊断闸门，不是万能故事模板。

## 何时用

- 内容方向、脑暴、选题、脚本、分镜、卡片、海报、视频、网页、Deck、社媒包装。
- 用户只给了一个模糊想法，但想做成可发布内容。

不需要用：纯文件操作、代码修复、只改文档结构、只做语言润色。

## 先做兴趣成立性判断

1. 受众：给谁看？他们带着什么兴趣或身份进入。
2. 观看回报：留下能得到什么？笑、共鸣、惊奇、美感、实用、悬念、参与感、角色依恋。
3. 具体证明：哪个确切画面/动作/台词/揭示能兑现回报。
4. 持续能力：回报有没有足够变化支撑计划时长/页数。
5. 专属性：遮掉名字后能否无损替换？能替换说明不够专属。

"展示一座赛博城市""介绍这个角色"是题材句，不是观看回报。

## 三种闸门结果

- 通过：受众、回报、证明瞬间都明确 → 进入生成。
- 有潜力但未解决：内核有意思，但最强瞬间/受众/机制还不清楚 → 保留内核，给 2-3 个聚焦方向。
- 暂不生产：只依赖题材、IP 认知或看似完整的结构 → 说明问题，给替代方向。

不得靠加事故、反派、反转把"暂不生产"伪装成"通过"。

## 兴趣机制（先选机制，再选结构）

| 主要机制 | 观众看什么 | 组织逻辑 |
|---|---|---|
| 叙事事件 | 发生了什么、改变了什么 | 处境→压力→选择→后果 |
| 喜剧 | 错位、时机、升级 | 正常→偏离→落点 |
| 共鸣 | "这太像我了" | 识别→细节累积→精准落点 |
| 奇观/发现 | 陌生、隐藏、第一次被具体化 | 异常入口→连续揭示→最强发现 |
| 知识/实用 | 理解或学会一件事 | 问题→演示→可用结果 |
| 过程/变化 | 进展、制作、转化 | 目标→可见阶段→完成对比 |
| 氛围/感官 | 情绪、质感、节奏、美感 | 感官承诺→深化→情绪完成 |
| 角色魅力 | 独特反应、脆弱、关系 | 显影处境→角色行为→认知加深 |
| 参与/选择 | 比较、预测、影响后续 | 清晰选项→有意义差异→回应 |

只有确实存在预期落差、阻碍或后果时才用 Hook→Conflict→Payoff。

## 不可违反

- 不为补齐结构发明冲突、升级、惩罚、反转、CTA。
- 不假设所有好内容都需要冲突。
- 不把题材、IP、形式、审美词、制作技术当观看理由。
- 可以判断一个方向暂时不值得生产。
- 闸门默认内部执行，不要每轮都甩一张检查表给用户。
